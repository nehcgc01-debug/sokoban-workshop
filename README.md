推箱工坊 · Sokoban Workshop

一个以温暖工坊为背景的 Godot 推箱子原型。玩家接受工单，将木箱送到目标位置，并在有限的牵引次数中规划路线。项目包含内置关卡、实验机制和关卡编辑器。

运行方法
1. 使用 Godot 4.6.x 标准版打开本仓库中的 project.godot。
2. 导入完成后按 F5 运行。
3. 在主菜单选择“开始游戏”进入关卡，或选择“关卡编辑器”创作。
项目使用 Compatibility 渲染器。首次冷导入曾出现字体缓存报错，重新导入后可运行；如遇问题，可等待资源导入完成并重新打开工程。

游戏内容
- 11 个主线关卡：从基础推箱逐步引入有限次数的牵引。
- 5 张实验关卡：T1、T2、T3、T2b 与 C1，用于探索工具箱和对照关卡。
- 工具箱实验机制：将工具箱推或拉到工作台后可获得一次牵引，牵引最多储存两次。
- 工坊情境：实验委托完成后，场景中的灯、炉火等会发生变化，并记录在休息角。
- 关卡编辑器：支持设计、保存、读取、试玩、自解性检查及分享码。
操作
- 方向键 / WASD：移动和推箱。
- Shift + 方向键：按关卡规则牵引箱子。
- Z：撤销；R：重开；H：查看提示；B：在支持时返回出错前的可解局面。
- 编辑器内可使用鼠标和界面按钮放置、擦除、保存、读取、检查及试玩；具体快捷键以游戏界面提示为准。
测试与已知限制
- 源码在隔离环境使用 Godot 4.6.3 运行 38 套、1076 项自动断言，并对 11 张主线和 5 张实验关进行了求解验证。
- Windows 发行包已进行限定范围实机验收：启动、主线第 1 关与 T1 通关、T2 提示切换、小窗口弹窗，以及编辑器保存、读取和试玩返回。
- 存档故障通过隔离数据与模拟方式进行了测试；真实断电、磁盘写满、声音听感、连续动画流畅度及陌生玩家盲测尚未完整验证。
- 备份保留上一份记录；从备份恢复时，最近一次成绩可能不在。实验版本使用独立存档目录，不与旧版共用。
- 这是可交互的实验原型，并非已经完成商业发行的产品。菜单中的“实验版 3”角标是保留的旧文字，不代表实际源码版本。
制作与 AI 辅助

项目从我早期制作的 Godot 推箱子原型出发。我提出了温暖工坊、角色与视觉方向、玩法和迭代要求，并参与原型搭建、试玩及设计决策。后续代码、界面、关卡、素材整合与测试使用了 AI 辅助；Claude 和 Codex 参与了开发、测试或评审。实验内容及验证过程见仓库中的相关记录。

拉箱并非本项目首创；本作尝试围绕有限牵引、失败恢复和工坊委托设计玩家体验。字体及素材来源和许可见项目内相关说明。

迭代过程： 项目从基础推箱与关卡编辑器逐步发展，加入有限牵引、死局反馈、实验工具箱和工坊委托。通过试玩反馈、自动测试与故障模拟持续修正操作提示、界面及存档恢复问题。详细改动见仓库中的版本记录。
