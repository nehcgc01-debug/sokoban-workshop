本分支 `post-submission-improvements` 是**截止后的持续迭代**，基于 BlindPrep v2。它不是截止前提交版本，不替换原提交。原有 main 和提交历史保留；本地准备完成后等待所有者确认，尚未推送、合并或发布。

## 本轮范围

- 主线 11 关结束且主线记录齐全时，若休息角仍有委托，终局优先邀请按 Enter / N 回菜单查看剩余委托，与菜单的开始游戏焦点和选关推荐一致。
- 四项委托完成后邀请创作或回菜单重玩；加班单仍可自由选择，不计入完成条件。

## 安全启动

需要已有 **Godot 4.6.x 标准版 Windows EXE**，包内不含引擎。使用 Compatibility 渲染器。

在完整解压、可写的项目目录中双击 Start_BlindTest.exe，粘贴引擎路径，再选新测试者或继续会话。启动器使用本机 Windows .NET Framework 4.x，EXE 未签名；安全警告或组织策略阻止时请停止，不绕过。见 HOST_OPERATIONS.md、PLAYER_CARD.txt；构建源码见 launcher/HostLauncher.cs 与 launcher/BUILD_LAUNCHER.md。

所有主持人数据应位于本副本 .host-private/Sessions/。启动器核对 Godot 实际 user://；不匹配就停止。**直接打开 project.godot 或 F5 不保证隔离**，因为应用存档名保持兼容。不要删除或重置默认 Windows 存档。请勿把私有会话、整目录缓存或试玩记录上传。

源码与测试含游戏内提示及解法；主持人保管文件夹，首次玩家只看玩家卡和游戏窗口。
